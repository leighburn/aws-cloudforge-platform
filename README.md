# 🚀 AWS CloudForge Platform

> Production-ready AWS DevOps project demonstrating Docker containerisation, AWS EC2 deployment, Linux administration and Git version control.

---

## 🌍 Project Overview

AWS CloudForge Platform is a production-style DevOps project that demonstrates how modern cloud applications are developed, containerised and deployed.

This project covers the complete workflow from local development to deployment on an AWS EC2 Linux server using Docker and GitHub.

---

## ✨ Features

- ✅ Responsive HTML/CSS/JavaScript application
- ✅ Docker containerisation
- ✅ Nginx web server
- ✅ AWS EC2 deployment
- ✅ Git & GitHub version control
- ✅ Linux administration
- ✅ SSH remote management
